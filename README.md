# Prabhat Ranjan Singh

Associate Professor, School of Software, Quanzhou University of Information Engineering (QZUIE)

I work on swarm intelligence, global optimization, machine learning, natural language processing, and networked systems, with applications in smart cities, edge and cloud computing, and applied AI.

## Research

- Metaheuristics and swarm intelligence, including Spider Monkey, Ludo, Artificial Bee Colony, and Lizard-Moth Flame Optimization (L-MFO)
- Energy-aware cloud and collaborative edge computing
- AI for networks and smart cities

Code for the L-MFO algorithm is in [L-MFO-Code](https://github.com/prabhatranjansingh/L-MFO-Code).
